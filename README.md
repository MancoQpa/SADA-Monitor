# Monitor SADA IEC 61850 — sitio

Landing page del **Monitor SADA IEC 61850**, un monitor SCADA multi-fabricante
para medidores e IEDs sobre IEC 61850 (MMS): descubrimiento automático de nodos,
dashboard web en tiempo real, calidad de energía (PQM) y registro histórico
CSV/Excel.

- 🌐 **Sitio:** https://mancoqpa.github.io/SADA-Monitor/
- ⬇️ **Descargas:** [releases](https://github.com/MancoQpa/SADA-Monitor/releases)
- 📄 **Licencia:** GPLv3

> Este repositorio contiene únicamente la página del proyecto y el instalador
> distribuible (solo código propio). `iec61850.dll` (libiec61850, GPLv3) no se
> distribuye: la aporta el usuario final.
